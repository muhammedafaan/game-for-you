GAME FOR YOU — FREE BROWSER GAME WEBSITE

WHAT'S INCLUDED
- index.html: a responsive, self-contained website.
- 100 game entries across Arcade, Puzzle, Brain, and Action categories.
- 12 game mechanics: number guessing, memory match, rock-paper-scissors, tic-tac-toe, reaction test, math rush, click challenge, quiz, catch the star, dodge zone, color sequence, and snake.
- Search, category filters, favorites saved in this browser, and mobile-friendly layout.

IMPORTANT
The 100 entries are themed variations built on 12 simple mechanics, not 100 unique commercial-quality games. This is a working starter demo you can expand.
No accounts, backend, paid assets, or build tools are required.

RUN LOCALLY ON WINDOWS
1. Extract the ZIP file.
2. Open the game-for-you folder.
3. Double-click index.html.
4. It opens in Chrome, Edge, or Firefox.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/.
2. Create a new public repository named game-for-you.
3. Upload index.html and README.txt (or upload the ZIP's extracted files).
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish. Your website URL will be shown on the Pages settings screen.

You can also deploy the folder with https://vercel.com/ by importing the GitHub repository. Keep this project as a static site; no build command is needed.

SAFETY & PRIVACY
- The site does not collect accounts, names, passwords, or payment details.
- Favorites are stored locally in the visitor's browser using localStorage.
- Do not add secret API keys or passwords to public repositories.
- Only use games and assets you created or have permission to use.
